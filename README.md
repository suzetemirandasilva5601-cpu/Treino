# Treino Tryhard · PPL rotativo

App web (funciona offline) para executar e acompanhar o treino Push/Pull/Legs com descanso rotativo montado a partir do vídeo [“Se eu fosse tryhard nos ganhos…” do Samuel Meller](https://www.youtube.com/watch?v=DEUkEk5YLI0).

- Registro de carga, reps e RIR por série, com sugestão automática de progressão (dupla progressão 5–9 reps)
- Cluster, backoff, Kelso shrug e rest-pause, além de timer de descanso
- Gráficos de 1RM estimado e volume, séries por músculo e peso corporal
- Imagens dos exercícios embutidas (offline) e links para vídeos de execução

Os dados ficam salvos no navegador (localStorage). Use “Exportar JSON” na aba Histórico para fazer backup.

Imagens: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (domínio público).
